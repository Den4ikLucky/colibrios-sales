1.范围

该政策解释了 ColibriOS 网站、其 Telegram Mini 应用程序以及通过 Lava.top 购买产品时的数据处理。项目名称并不表示独立的法人实体。适用有关个人数据的强制性规则，包括俄罗斯联邦联邦法第 152-FZ 号（如适用）。

2. 处理哪些数据

  • 计算器和诊断： 所选角色、数值估算、小时数、每小时成本、发布百分比和流程响应。计算在浏览器中执行。无需接触即可进行诊断。
  • 浏览器内存： 匿名草稿诊断、选定的选项卡和试用窗口时间。该数据存储在该设备的 localStorage 中。旧的接口标记可能会保留，直到存储被清除。
  • B2B应用： 姓名、指定联系人、业务描述、任务、尝试和预期结果。在本地模式下，数据仅用于下载设备上的文件，不会发送给运营商。
  • 当设计启用时： 电子邮件、所选产品、订单号、金额、货币和确认的付款状态；通过 Telegram 发出时：确认的帐户 ID 和提供访问权限所需的信息。
  • 技术数据： 托管和支付服务可以根据自己的规则处理IP地址、访问时间、浏览器信息和技术日志。请勿发送客户的护照数据、密码、银行代码或个人信息。

3. 目标和理由

目标：执行所要求的计算；回应自愿请求；订立并执行协议；将付款与订单进行匹配；授予和恢复访问权限；履行法律义务并考虑请求。理由：用户为签订和履行合同而发起的行动、适用的法律义务以及需要时的单独同意。对广告的同意不包含在对处理申请的同意中。

4. 转让及对外服务

该网站托管在 GitHub Pages 上。网站提供静态字体；广告像素和分析计数器在此组件中未连接。托管基础设施技术日志不等于本地诊断响应。

Lava.top 及其支付合作伙伴根据自己的条款和政策处理结帐和支付数据。完整的卡详细信息在安全支付页面上输入，不会传输到 ColibriOS 表单。卖方仅收到订购、会计、支持和访问所需的信息。

官方 Telegram Web App SDK 已加载到 Mini App 中。 Telegram 根据自己的规则处理其平台数据。诊断结果仅通过支持的启动场景中的单独用户操作传输到机器人；单击不被视为机器人已确认收到。支付时，服务器必须验证 Telegram 数据的真实性。

在启用服务器数据收集之前，卖方确定实际处理地点、接收者范围、本地化需求以及跨境传输的条件。本政策本身并不取代通知、同意或其他必需的行动。不提供用于他人广告的数据的销售和转让。

五、储存与保护

本地草稿保留在设备上，直到用户使用应用程序或浏览器设置将其删除。下载后，文件将保存到设备并由用户管理。此构建不会将请求文本和联系人写入 localStorage。

连接服务器处理时，数据将存储在合同、支持、强制会计和法律索赔保护所需的范围和持续时间内。在基础结束时，数据将被删除或匿名化，除非法律要求进一步存储。使用访问控制、安全传输和支付通知控制。密钥不包含在站点的公共文件中。

6. 权利和上诉

用户有权要求提供有关处理、澄清、阻止或删除数据的信息、撤回同意以及行使其他合法权利。在付款开始之前，该请求将发送至订单中和网站上指定的卖方工作联系人。注明您的回复联系人以及您的订单号（如果有）；不要发送不必要的文件。法律回复截止日期和删除排除条款保持不变。

撤回同意并不取消根据其他法律依据仍然必要的处理。用户有权向授权的数据保护机构或法院提出上诉。在诊断中，“从设备删除测试响应”按钮会删除其本地草稿；完整的站点数据清除是在浏览器设置中执行的。

七、变更及联系方式

修订日期显示在页面的开头。目的、接收者或处理方法的重大变更将在相关数据收集之前披露，并在必要时附上新的同意书。在进行商业处理之前，需要支持联系方式和完整的操作员详细信息。
